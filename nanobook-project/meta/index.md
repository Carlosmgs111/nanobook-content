## Qué es Nanobook

Nanobook es un generador de sitios estáticos pensado para publicar contenido técnico organizado: libros, capítulos, artículos y documentación de proyecto. Nace de la necesidad de tener una base ligera, jerárquica y fácil de mantener, donde el contenido viva en Markdown y la navegación se genere a partir de la estructura de carpetas.

## Estado actual

El proyecto está en **fase alpha**. El objetivo inmediato es lograr un uso mínimo de documentación con una navegación clara, un tema usable y una arquitectura que permita escalar sin reescribir todo desde cero.
