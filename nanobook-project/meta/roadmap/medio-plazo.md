# Medio plazo

Horizonte: próximos 2–3 meses. El objetivo es pasar de "proyecto usable" a "producto con identidad propia".

## Editor integrado

- [ ] Finalizar el editor en navegador con preview en tiempo real.
- [ ] Soporte para edición directa de frontmatter con validación.
- [ ] Flujo de guardado claro: local, remoto (GitHub) o ambos modos.

## Modelo SSR puro

- [x] Consolidar `output: "server"` como único modo.
- [x] Eliminar `OUTPUT_MODE` y las bifurcaciones estático/dinámico.
- [x] Documentar el modelo server-first y `CONTENT_SOURCE`.
- [ ] Estabilizar `FileSystemRepository` y `GitHubRepository` en producción.
- [ ] Definir flujo de escritura de vuelta a GitHub para el editor.

## Experiencia de contenido

- [ ] Búsqueda full-text dentro del contenido.
- [ ] Soporte para etiquetas y filtros por tag.
- [ ] Páginas de índice más informativas (últimas actualizaciones, progreso de lectura).

## UX/UI

- [ ] Pulir animaciones y transiciones del tema.
- [ ] Mejorar la tipografía y el espaciado en bloques de código.
- [ ] Añadir variantes de componentes para diferentes densidades de información.
