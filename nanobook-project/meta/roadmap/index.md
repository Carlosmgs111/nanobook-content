# Roadmap de Nanobook

Este documento centraliza el estado del proyecto y la dirección de desarrollo. Se divide en horizontes para separar lo que estamos construyendo ahora de lo que aún está en exploración.

| Fase | Estado | Enfoque |
|---|---|---|
| [Fase 0 — Alpha](./fase-0-alpha) | En progreso | Documentación mínima usable: navegación, tema, build estable. |
| [Corto plazo](./corto-plazo) | Pendiente | Mejoras inmediatas para dejar la alpha lista. |
| [Medio plazo](./medio-plazo) | Pendiente | Features que consolidan el producto. |
| [Largo plazo](./largo-plazo) | Pendiente | Ideas y direcciones futuras. |

## Cómo usar este roadmap

- Los items marcados como `[x]` están implementados o decididos.
- Los items `[ ]` están pendientes o en diseño.
- Cuando una fase se completa, se actualiza el estado y se mueve el foco al siguiente horizonte.
