# Largo plazo

Horizonte: más allá de 3 meses. Estas ideas están en exploración y pueden cambiar según cómo evolucione el uso del producto.

## Extensibilidad

- [ ] Sistema de plugins para transformar contenido antes del renderizado.
- [ ] Soporte para múltiples temas visuales intercambiables.
- [ ] Integraciones con fuentes externas: Notion, CMS headless, S3.

## Colaboración

- [ ] Comentarios o anotaciones en línea sobre el contenido.
- [ ] Flujo de revisiones antes de publicar cambios.
- [ ] Sincronización multi-repositorio.

## API y distribución

- [ ] Exponer una API JSON del contenido para consumo externo.
- [ ] Generar feeds (RSS/Atom) por sección.
- [ ] Soporte para exportar a PDF o ePub desde libros.

## Producto

- [ ] Definir un modelo de licenciamiento claro.
- [ ] Plantillas de inicio rápido para nuevos sitios.
- [ ] Documentación de usuario orientada a no desarrolladores.
